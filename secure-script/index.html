Mã hoá script thành tệp .aia + key script

AES-256-GCM theo từng khối, khoá sinh bằng PBKDF2-SHA256 từ thời gian tạo (năm/tháng/ngày/giờ/phút/giây/mili-giây) + link key script + mật khẩu. Header giữ thời gian và link key ở dạng đọc được để nhận biết. Tối đa 5 GiB, tăng kích thước chỉ ~0,002%.

chạy 100% trong máy bạn không upload lên máy chủ miễn phí

2. Tuỳ chọn mã hoá

Giải thích

Link key script là chuỗi tham gia tạo khoá, nên nếu đổi link thì không giải mã được. Hạn dùng chỉ kiểm tra phía client. Bật “nhúng mật khẩu” sẽ tiện nhưng ai có key script là chạy được.

Dùng chung: mọi bản mã dùng chung ./aia.key.js ⇒ chỉ cần gửi 1 link + mật khẩu. Riêng từng tệp: mỗi tệp một key script, tách biệt hơn.

Đường dẫn tới script chứa key (tệp khoá sinh ra). VD https://cdn.example.com/key.js hoặc ./keys/abc.js.

chưa đặt

Mặc định bỏ qua mật khẩu cho tiện nhận biết — ai có đoạn code cũng mở được. Muốn bảo vệ thật thì chọn kiểu có mật khẩu.

Nhiều vòng = chống dò mật khẩu tốt hơn, nhưng chậm hơn khi mở khoá (mỗi lần vài phần trăm giây).

Chỉ ảnh hưởng RAM/CPU khi chạy, không làm tăng đáng kể kích thước.

Sau mốc này, key script sẽ từ chối giải mã.

Kích thước tăng bao nhiêu?

          
Chỉ 16 byte tag cho mỗi khối + header ~1 KB. Với tệp 1 MB dùng khối 1 MiB: tăng 17 byte (~0,002%). Không dùng base64.

          
Không treo máy

          
Mã hoá theo luồng, mỗi lúc chỉ giữ 1 khối trong RAM. Script chạy trong Web Worker nên giao diện vẫn mượt.

            không thay thế mật khẩu.

            aia.key.js dùng chung cho mọi lần mã hoá và mọi người.
    • 
          
  • Ba kiểu bảo vệ: không mật khẩu (mặc định, chép là chạy), nhúng sẵn,
            hoặc hỏi khi chạy. Không mật khẩu = ai có code cũng mở được.
    • 
          
  • Khoá tệp ngẫu nhiên chỉ nằm trong key script / header đã bọc → thiếu key là không mở được.
    • 
          
  • Khoá gắn với thời gian tạo (đến mili giây) + link key + mật khẩu.
    • 
          
  • Header giữ thời gian/link key không mã hoá để nhận biết.
    • 
          
  • Tăng kích thước gần như bằng 0; không treo máy; script vẫn chạy bình thường.

    7. 
      
  7. Muốn nhúng vào web: thêm <script src="./key.js"></script> rồi gọi AIA_UNLOCK.run({execute:true}).
    8.

        bấm lỗi để nhảy tới dòng. Có nút Mã hoá code này và Đăng lên GitHub.
    9. 
      
  9. Chống soi (cột phải tab Lập trình): dán link thật + khoá mở → tải về trang trắng
        …-trang-trang.html; chỉ link kèm #k=… mới mở ra nội dung thật.
    10. 
      
  10. Nút GitHub (góc trên): tab 1 nhập API key → tab 2 tạo dự án (tự đẩy code) →
